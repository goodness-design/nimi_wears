# Nimi_luxe Wears 👗🛍️

**Nimi_luxe Wears** is a modern fashion e-commerce website designed to showcase stylish clothing and accessories for men and women. The project focuses on creating a clean, elegant, and responsive shopping experience with curated fashion collections and product displays.

## ✨ Features

* 🏠 **Modern Landing Page** — Attractive hero section introducing Nimi_luxe.
* 🆕 **New Arrivals** — Showcase recently added products.
* 👨 **Men's Collection** — Browse shirts, Jalabiyas, tops, shorts, and pants.
* 👩 **Women's Collection** — Browse dresses, tops, skirts, pants, and other clothing.
* 👗 **Fashion Collections** — Dedicated sections for:

  * Jackets
  * Owanbe
  * Aso-Ebi wears
* 🛒 **Shopping Interface** — Includes search, wishlist, account, and shopping-cart icons.
* 💳 **Secure Payment Section** — Highlights secure payment options.
* 🚚 **Shipping Information** — Promotes fast shipping.
* 💬 **Live Chat Feature** — Provides a section for customer support.
* 📧 **Newsletter Subscription** — Visitors can subscribe and receive a discount on their first order.
* 📱 **Responsive Navigation** — Includes a mobile menu interface.
* 🦶 **Detailed Footer** — Includes shopping links, help resources, newsletter signup, legal links, and social media links.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactive functionality
* **Bootstrap 5** — UI components and responsive utilities
* **Google Fonts** — Custom typography

The project currently uses Bootstrap 5.3.8 and the Allura Google Font.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Nimi_luxe-Wears.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd Nimi_luxe-Wears
```

### 3. Run the website

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, use **VS Code Live Server** or another local development server.

## 🎨 Website Sections

The homepage introduces visitors to Nimi_luxe with a fashion-focused hero section and a **Shop Now** call-to-action.

The New Arrivals section displays products with their names, colors, prices, and "NEW" badges.
